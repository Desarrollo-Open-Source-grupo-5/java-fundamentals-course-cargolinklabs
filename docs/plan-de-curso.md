# Plan del Curso: Fundamentos de Java para Principiantes

## Descripción general

**Fundamentos de Java para Principiantes** es un curso introductorio de programación diseñado para estudiantes de secundaria de 12 a 17 años, sin experiencia previa.

El curso está compuesto por **10 lecciones en video, con una duración total de 2 horas, 1 minuto y 33 segundos**. A lo largo de las sesiones, los estudiantes aprenderán progresivamente los conceptos fundamentales de Java, desde la creación de su primer programa hasta el desarrollo de una aplicación básica utilizando programación orientada a objetos.

Todas las prácticas pueden realizarse mediante [OnlineGDB](https://www.onlinegdb.com/online_java_compiler), un compilador de Java accesible desde el navegador, sin necesidad de instalar herramientas adicionales.

## Objetivo del curso

Introducir a los estudiantes en los fundamentos de la programación con Java mediante explicaciones sencillas, ejemplos prácticos y ejercicios que desarrollen progresivamente sus habilidades de resolución de problemas.

## Metodología de aprendizaje

Cada lección sigue una secuencia práctica:

1. **Introducción:** presentación del tema y de los conceptos fundamentales.
2. **Demostración:** explicación de ejemplos mediante código Java.
3. **Práctica:** desarrollo o modificación de programas en OnlineGDB.
4. **Verificación:** ejecución del código y comprobación de resultados.
5. **Refuerzo:** aplicación de los conceptos mediante ejercicios.

Los estudiantes pueden acceder a los archivos iniciales de práctica en el directorio [`starter-files`](../starter-files/) y consultar los ejemplos disponibles en [`lessons`](../lessons/).

## Proyecto final: Sistema de Gestión de Estudiantes

Como actividad integradora, los estudiantes desarrollarán un programa de consola que permita registrar información académica y gestionar calificaciones.

### Funcionalidades principales

- Registrar información de un estudiante.
- Ingresar y validar calificaciones.
- Calcular el promedio de notas.
- Determinar si un estudiante está aprobado o desaprobado.
- Utilizar un menú interactivo para ejecutar diferentes operaciones.

### Conceptos aplicados

El proyecto integra clases y objetos, encapsulación, arreglos, métodos, `Scanner`, bucles `while`, estructuras `switch` y condicionales.
