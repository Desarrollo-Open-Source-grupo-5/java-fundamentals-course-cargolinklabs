# Rúbrica y revisión de la entrega

Los criterios y puntajes corresponden a la diapositiva de evaluación del equipo. Las comprobaciones sirven para revisar los materiales antes de la entrega.

| Criterio | Puntos | Comprobación |
| --- | ---: | --- |
| C01 · Estructura | 4 | Hay 10 lecciones ordenadas en tres módulos. Cada lección tiene objetivo, ejemplo y práctica. |
| C02 · Precisión técnica | 4 | Los ejemplos compilan, la demostración coincide con el código y las explicaciones usan los conceptos de Java correctamente. |
| C03 · Engagement | 5 | El video se dirige a principiantes, muestra ejemplos cotidianos e incluye una pausa o actividad de práctica. |
| C04 · Producción | 4 | Se escucha la voz, la pantalla es legible y el video se publica como no listado. |
| C05 · Documento | 3 | El README enlaza el material del curso y el repositorio registra los aportes revisados de los cinco integrantes. |
| **Total** | **20** | |

Antes de entregar, abre cada enlace de video con una sesión sin iniciar y verifica que la grabación se pueda reproducir. Revisa que la pantalla y el audio se ajusten a los requisitos acordados por el equipo.
