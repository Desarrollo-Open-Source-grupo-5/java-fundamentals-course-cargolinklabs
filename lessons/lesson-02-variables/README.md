# Lección 02 · Variables y tipos de datos

**Duración** · 6 min  
**Diapositiva** · 7  
**Video** · Pendiente de enlace

## Objetivo

Declarar y usar int, double, boolean, char y String. Explorar la división entera y el residuo.

## Ejemplos

- [Variables.java](Variables.java)
- [OperacionesBasicas.java](OperacionesBasicas.java)

Abre [OnlineGDB](https://www.onlinegdb.com/online_java_compiler), crea los archivos del ejemplo y selecciona la clase que contiene el método `main`. Si el editor exige `Main.java`, en un ejemplo de un solo archivo puedes renombrar temporalmente la clase principal a `Main`. En ejemplos de varios archivos conserva un archivo por clase.



Para ejecutar en local, abre una terminal en esta carpeta.

```bash
javac --release 17 -encoding UTF-8 Variables.java OperacionesBasicas.java
java Variables
java OperacionesBasicas
```

## Práctica

1. Abre el [ejercicio inicial](../../starter-files/lesson-02-variables/).
2. Completa la ficha y calcula cuántos equipos completos de 4 puedes formar con 17 personas y cuántas sobran.
3. Comprueba el resultado. 4 equipos y 1 persona sin equipo.
