# Lección 03 · Operadores y expresiones

- **Duración** · 6 min
- **Diapositiva** · 8
- **Video** · [Ver en YouTube](https://youtu.be/r5D_MPz-eQ0)

## Objetivo

Combinar comparaciones con &&, || y !. Usar paréntesis para controlar la precedencia.

## Ejemplos

- [Operadores.java](Operadores.java)
- [Calculadora.java](Calculadora.java)

Abre [OnlineGDB](https://www.onlinegdb.com/online_java_compiler), crea los archivos del ejemplo y selecciona la clase que contiene el método `main`. Si el editor exige `Main.java`, en un ejemplo de un solo archivo puedes renombrar temporalmente la clase principal a `Main`. En ejemplos de varios archivos conserva un archivo por clase.

Con precio 100 y descuento 20 %, el ejemplo imprime un ahorro de 20 y un precio final de 80.

Para ejecutar en local, abre una terminal en esta carpeta.

```bash
javac --release 17 -encoding UTF-8 Operadores.java Calculadora.java
java Operadores
java Calculadora
```

## Práctica

1. Abre el [ejercicio inicial](../../starter-files/lesson-03-operadores/).
2. Calcula el ahorro y el precio final de una compra. Añade una condición booleana que indique si el total supera 75 soles.
3. Comprueba el resultado. Con S/ 100 y 20 % de descuento, el ahorro es S/ 20, el precio final es S/ 80 y la condición es verdadera.
