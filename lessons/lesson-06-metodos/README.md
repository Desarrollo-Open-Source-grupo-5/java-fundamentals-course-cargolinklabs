# Lección 06 · Métodos y reutilización

**Duración** · 6 min  
**Diapositiva** · 12  
**Video** · Pendiente de enlace

## Objetivo

Definir parámetros, llamar métodos y devolver valores con return.

## Ejemplos

- [Metodos.java](Metodos.java)
- [CalculadoraMetodos.java](CalculadoraMetodos.java)

Abre [OnlineGDB](https://www.onlinegdb.com/online_java_compiler), crea los archivos del ejemplo y selecciona la clase que contiene el método `main`. Si el editor exige `Main.java`, en un ejemplo de un solo archivo puedes renombrar temporalmente la clase principal a `Main`. En ejemplos de varios archivos conserva un archivo por clase.



Para ejecutar en local, abre una terminal en esta carpeta.

```bash
javac --release 17 -encoding UTF-8 Metodos.java CalculadoraMetodos.java
java Metodos
java CalculadoraMetodos
```

## Práctica

1. Abre el [ejercicio inicial](../../starter-files/lesson-06-metodos/).
2. Implementa calcularArea(base, altura) para devolver el área de un triángulo y prueba dos llamadas desde main.
3. Comprueba el resultado. Las entradas (10, 5) y (3, 7) deben dar 25.0 y 10.5.
