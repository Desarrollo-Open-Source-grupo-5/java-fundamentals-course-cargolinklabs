# Lección 05 · Bucles for y while

**Duración** · 7 min  
**Diapositiva** · 11  
**Video** · Pendiente de enlace

## Objetivo

Distinguir contador, condición y actualización en for y while.

## Ejemplos

- [BucleWhile.java](BucleWhile.java)
- [BucleFor.java](BucleFor.java)
- [TablaMultiplicar.java](TablaMultiplicar.java)

Abre [OnlineGDB](https://www.onlinegdb.com/online_java_compiler), crea los archivos del ejemplo y selecciona la clase que contiene el método `main`. Si el editor exige `Main.java`, en un ejemplo de un solo archivo puedes renombrar temporalmente la clase principal a `Main`. En ejemplos de varios archivos conserva un archivo por clase.



Para ejecutar en local, abre una terminal en esta carpeta.

```bash
javac --release 17 -encoding UTF-8 BucleWhile.java BucleFor.java TablaMultiplicar.java
java BucleWhile
java BucleFor
java TablaMultiplicar
```

## Práctica

1. Abre el [ejercicio inicial](../../starter-files/lesson-05-bucles/).
2. Imprime una tabla de multiplicar del 1 al 10 usando for. Después reescribe el bucle con while.
3. Comprueba el resultado. Para 7, imprime 10 filas. La primera termina en 7 y la última en 70.
