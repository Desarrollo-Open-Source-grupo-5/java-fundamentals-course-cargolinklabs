# Lección 01 · ¿Qué es programar y qué es Java?

**Duración** · 6 min  
**Diapositiva** · 6  
**Video** · Pendiente de enlace

## Objetivo

Leer el punto de entrada main y mostrar mensajes con System.out.println.

## Ejemplos

- [HolaMundo.java](HolaMundo.java)

Abre [OnlineGDB](https://www.onlinegdb.com/online_java_compiler), crea los archivos del ejemplo y selecciona la clase que contiene el método `main`. Si el editor exige `Main.java`, en un ejemplo de un solo archivo puedes renombrar temporalmente la clase principal a `Main`. En ejemplos de varios archivos conserva un archivo por clase.



Para ejecutar en local, abre una terminal en esta carpeta.

```bash
javac --release 17 -encoding UTF-8 HolaMundo.java
java HolaMundo
```

## Práctica

1. Abre el [ejercicio inicial](../../starter-files/lesson-01-intro/).
2. Imprime un saludo y, en una segunda línea, el nombre de tu ciudad.
3. Comprueba el resultado. Con Lima, la segunda línea debe contener Lima.
