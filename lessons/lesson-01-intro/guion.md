Pues alguien lo programó. Una persona escribió instrucciones, y la computadora las siguió una por una. En este curso vas a aprender a escribir esas instrucciones usando un lenguaje que se llama Java. Y lo mejor: no necesitas instalar nada ni saber nada de antes. Solo necesitas un navegador, como el que usas para ver este video.

### [00:45-01:55] ¿Qué es programar?
**En pantalla:** Dos columnas: a la izquierda una receta de sándwich con pasos numerados; a la derecha los mismos pasos escritos como instrucciones de programa.

**Narración:**
> Empecemos por lo básico: ¿qué significa programar? Programar es darle instrucciones a una computadora para que haga una tarea. Piensa en una receta de cocina para hacer un sándwich. Paso uno: toma dos rebanadas de pan. Paso dos: unta mantequilla en una. Paso tres: pon el queso encima. Paso cuatro: cierra el sándwich. Si sigues los pasos en orden, el sándwich sale bien. Pero si cambias el orden, o te saltas un paso, el resultado es un desastre. Con las computadoras pasa lo mismo, con una diferencia importante: la computadora es muy obediente, pero no piensa por sí sola. Hace exactamente lo que le escribes, ni más ni menos. Por eso las instrucciones tienen que ser claras y estar en el orden correcto. A esas instrucciones escritas las llamamos código, y a la persona que las escribe, programador o programadora. Tú vas a ser uno hoy.

**Anotación:** "Programar = dar instrucciones claras y en orden".

### [01:55-03:00] ¿Qué es Java?
**En pantalla:** Línea de tiempo simple: "1995: nace Java". Después tres iconos: videojuego, celular, computadora.

**Narración:**
> Las computadoras no hablan español ni inglés. Entienden lenguajes de programación, que son como idiomas inventados para darles órdenes. Existen muchos, y hoy vamos a aprender uno llamado Java. Java nació en el año mil novecientos noventa y cinco y sigue siendo uno de los lenguajes más usados del mundo. ¿Por qué se usa tanto? Primero, porque un programa hecho en Java funciona en distintos sistemas, como Windows, Mac o Linux, sin tener que reescribirlo. Segundo, porque se usa para cosas muy variadas: el videojuego Minecraft en su versión de computadora está hecho con Java, y muchas aplicaciones de Android se programan con Java o con un lenguaje parecido. Y tercero, porque es un lenguaje ordenado, perfecto para aprender buenos hábitos desde el principio. Además, Java es gratuito de usar, así que no tienes que pagar nada.

**Anotación:** "Java: creado en 1995 · funciona en muchos sistemas · gratuito".

### [03:00-04:00] ¿Dónde escribimos el código? Conoce Replit
**En pantalla:** Abrir el enlace de Replit de la descripción. Señalar con el cursor tres zonas: la lista de archivos (izquierda), el editor donde se escribe el código (centro) y la consola donde aparece el resultado (derecha o abajo). Señalar el botón Run.

**Narración:**
> Para escribir código normalmente se instalan programas en la computadora, pero nosotros no lo haremos. Vamos a usar un editor en línea que se llama Replit. Un editor en línea es una página web donde puedes escribir código y ejecutarlo, todo dentro del navegador. Mira la pantalla. A la izquierda está la lista de archivos de tu proyecto. En el centro está el editor, que es la zona donde escribes. Y aquí está la consola, que es la ventana donde el programa muestra sus resultados. Finalmente, este botón, Run, que significa ejecutar, le dice a la computadora: «ahora sí, haz lo que escribí». El enlace de este editor, con todo preparado, lo vas a encontrar en la descripción de cada video.

**Anotación:** "Editor = donde escribes · Consola = donde ves el resultado · Run = ejecutar".

### [04:00-05:20] Tu primer programa: Hola Mundo
**En pantalla:** En Replit, escribir lentamente `HolaMundo.java` (ver `codigo-java-completo.md`, lección 1). Resaltar cada línea con un recuadro mientras se explica. Al final, pulsar Run y mostrar la consola.

**Narración:**
> Ahora sí, tu primer programa. Tradicionalmente, el primer programa de todo el mundo se llama «Hola Mundo». Escribimos public class HolaMundo. Una clase es como una caja donde guardamos nuestro programa, y su nombre debe ser igual al del archivo. Luego, public static void main, entre paréntesis String args. No te preocupes por memorizarlo: es la puerta de entrada, el lugar donde Java empieza a leer. Y ahora la línea que hace la magia: System punto out punto println, y entre comillas el texto que queremos mostrar. Al final del renglón, siempre un punto y coma, que es como el punto final de una oración. Las llaves abren y cierran cada bloque. Pulso Run, y mira: en la consola aparece «¡Hola, mundo!». ¡Acabas de ejecutar un programa en Java!

**Anotación:** "println = imprimir una línea de texto" · "El renglón termina con ;".
