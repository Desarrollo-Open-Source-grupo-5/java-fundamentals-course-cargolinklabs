# Lección 04 · Decisiones con if y else

- **Duración** · 6 min
- **Diapositiva** · 10
- **Video** · [Ver en YouTube](https://youtu.be/fHbGM7QOj6w)

## Objetivo

Evaluar condiciones en orden con if, else if y else.

## Ejemplos

- [Condicionales.java](Condicionales.java)
- [AdivinaNumero.java](AdivinaNumero.java)

Abre [OnlineGDB](https://www.onlinegdb.com/online_java_compiler), crea los archivos del ejemplo y selecciona la clase que contiene el método `main`. Si el editor exige `Main.java`, en un ejemplo de un solo archivo puedes renombrar temporalmente la clase principal a `Main`. En ejemplos de varios archivos conserva un archivo por clase.

El ejemplo de calificaciones usa una escala de 0 a 100. El proyecto final usa una escala de 0 a 20.

Para ejecutar en local, abre una terminal en esta carpeta.

```bash
javac --release 17 -encoding UTF-8 Condicionales.java AdivinaNumero.java
java Condicionales
java AdivinaNumero
```

## Práctica

1. Abre el [ejercicio inicial](../../starter-files/lesson-04-if-else/).
2. Completa la adivinanza para mostrar si el intento es menor, igual o mayor que el número secreto.
3. Comprueba el resultado. Con secreto 7 prueba los intentos 5, 7 y 9. Cada uno debe activar una rama distinta.
