# Buenas prácticas

- Usa nombres que indiquen el dato o la acción, por ejemplo `cantidadNotas` y `calcularPromedio`.
- Mantén los métodos enfocados en una tarea. `calcularPromedio` devuelve un valor y `mostrarInformacion` se encarga de imprimir.
- Guarda una clase pública por archivo. Ejecuta la clase que tiene `public static void main(String[] args)`.
- Prueba valores de borde, como 0, 11 y 20 en el registro de notas.
- Comenta la razón de una validación cuando el código por sí solo no la explique.
