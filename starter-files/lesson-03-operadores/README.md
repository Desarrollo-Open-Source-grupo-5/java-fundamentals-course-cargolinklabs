# Ejercicio 03 · Operadores y expresiones

Calcula el ahorro y el precio final de una compra. Añade una condición booleana que indique si el total supera 75 soles.

**Comprobación** · Con S/ 100 y 20 % de descuento, el ahorro es S/ 20, el precio final es S/ 80 y la condición es verdadera.
