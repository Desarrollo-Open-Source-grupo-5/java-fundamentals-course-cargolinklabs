# Contribuir al curso

1. Consulta tu rama en [Participación](docs/participacion.md).
2. Agrega el código, el guion y el ejercicio inicial de tus dos lecciones. Revisa que cada clase pública coincida con el nombre de su archivo.
3. Ejecuta `bash scripts/run-tests.sh` desde Git Bash o desde una terminal Bash con JDK 17 o superior.
4. Crea un commit descriptivo con tu cuenta y sube tu rama. Abre el pull request hacia `estructura-curso`.
5. En la revisión, indica qué probaste y agrega el enlace del video cuando esté publicado.

Para propuestas de documentación o correcciones, indica la lección afectada y describe cómo reproducir el resultado. Mantén el código y los archivos Markdown en UTF-8.
